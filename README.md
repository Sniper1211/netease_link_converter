# 网易云音乐链接转换器

粘贴网易云音乐的歌曲分享链接，一键提取歌曲 ID 并生成对应的媒体播放地址。纯前端单文件实现，无需后端、无需登录。

## 功能

- **链接识别**：支持网易云歌曲详情页链接及任意包含 `song?id=` 的分享链接
- **媒体地址生成**：自动拼接为 `http://music.163.com/song/media/outer/url?id={id}.mp3`
- **一键复制**：复制生成的媒体链接
- **快捷操作**：`Cmd/Ctrl + Enter` 快速转换
- **移动端适配**：响应式布局，桌面与移动端均可使用

## 使用

直接在浏览器中打开 `netease_link_converter.html` 即可使用，无需构建或安装依赖。

```bash
open netease_link_converter.html
```

也可将该 HTML 文件部署到任意静态托管服务。

## 示例

输入：

```
https://music.163.com/#/song?id=536096105&userid=19770550
```

输出：

```
http://music.163.com/song/media/outer/url?id=536096105.mp3
```

## 技术

- 单文件 HTML + CSS + 原生 JavaScript
- 无外部依赖，无网络请求
- 链接解析支持三种格式：
  - `/#/song?id={id}` 哈希路由
  - `?id={id}` 或 `&id={id}` 查询参数
  - `/song/{id}` 路径形式

## 声明

本工具仅做链接格式转换，不托管或存储任何音频文件。媒体链接的可用性、播放与下载权限取决于网易云音乐的服务规则、歌曲版权及网络环境。请仅用于你有权访问和使用的场景。
